법정동 코드 마이그레이션

업로드 규칙
  • xlsx(엑셀) 또는 csv 파일의 헤더에 (예: 행정동코드/시도명/시군구명/읍면동명/법정동코드/동리명/생성일자/말소일자)가 있어야 합니다.
  • 법정동코드는 10자리 문자열로 처리하며, 단위 꼬리값이 000 또는 00이면 해당 하위 단위는 "없음(null)"으로 저장합니다.
  • rank는 상위(리 없음)과 하위(리 있음)를 각각 1,2,3...으로 별도 카운트해 단일 컬럼에 저장합니다.
  • 말소 여부는 말소일자(dlt_dt)로만 판단하며, use_yn은 최종 dlt_dt 유무로만 결정합니다(활성=Y / 말소=NULL).
미리보기 후 페이지 이동은 서버 세션의 업로드 데이터를 사용합니다.
